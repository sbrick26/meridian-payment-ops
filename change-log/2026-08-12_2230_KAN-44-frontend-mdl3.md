# Change log — 2026-08-12_2230 — KAN-44: Frontend modernization — MDL 3.0 + WCAG 2.2 AA

## Prompt
KAN-44: Modernize the Held Payments screen to Meridian Design Language 3.0 and WCAG 2.2 AA.
Scope: `views/exceptions.ejs`, `views/detail.ejs`, `views/partials/header.ejs`, `public/payops.js`,
`public/mdl-3.css`. Server-side code, routes, tests, and governance files untouched.

## Files changed

### `views/partials/header.ejs`
- Added EJS compliance header (AC-3, SI-10, AU-2 / PCI Req. 7, 6.5).
- Removed `<link>` to `/public/vendor/bootstrap.css` (Bootstrap 2 — no longer loaded).
- Removed `<script>` for `/public/vendor/jquery-1.9.1.min.js` (EOL Jan 2016 — no longer loaded).
- Added `<link rel="stylesheet" href="/public/mdl-3.css">` after `payops.css`.

### `views/exceptions.ejs`
- Added EJS compliance header (AC-3, SI-10, AU-2 / PCI Req. 7, 6.5).
- All `<th>` elements: added `scope="col"`.
- Sortable column `<th>` elements: added `role="button"` and `aria-sort="none"`.
- Added **RISK** column header and data cell between AGE and Clerk columns (spec column order).
- `colspan="11"` on the empty-row cell updated to `colspan="12"` to match new column count.
- Status cell: replaced `<%- u.statusLabel(r.status) %>` with inline chip markup
  `<span class="chip chip-<status_lower>" aria-label="Status: <STATUS>"><STATUS></span>` using
  safe `<%= %>` interpolation (no raw HTML, values are server-controlled enums).
- Risk cell: new `<span class="chip chip-<risk_lower>" aria-label="Risk: <RISK_FLAG>"><RISK_FLAG></span>`.
- Row: removed `class="row-high"` color-only risk encoding; added `tabindex="0"` and
  `aria-selected="false"` for keyboard accessibility.
- Footer note: updated prose to reference chip label instead of "rows shaded red".

### `views/detail.ejs`
- Added EJS compliance header (AC-3, SI-10, AU-2 / PCI Req. 7, 6.5).
- All `<th>` elements in the three field tables and vendor table: added `scope="row"`.
- Status field: replaced `<%- u.statusLabel(row.status) %>` with inline chip markup.
- Flag (risk) field: replaced `<%- u.riskLabel(row.risk_flag) %>` with inline chip markup.
- Related items table status cell: replaced `<%- u.statusLabel(related[i].status) %>` with
  inline chip markup.
- Interfaces panel: added v2 links (`/api/v2/payment-status?ref=`, `/api/v2/payment-status?invoice=`,
  `/api/v2/risk-score?ref=`) as primary links; legacy links retained and labeled "(deprecated)".

### `public/payops.js`
- Added JS compliance header (AU-2 / PCI Req. 6.5).
- Replaced all jQuery calls with vanilla DOM equivalents:
  - `selectRow()`: `$(...).removeClass/addClass` → `classList.remove/add`; `$(...).html()` →
    `innerHTML`; added `setAttribute('aria-selected', ...)` on deselected and selected rows.
  - `toggleBlock()`: `$().is(':visible')` / `.hide()` / `.show()` → `style.display` toggle;
    `$(linkEl).html()` → `linkEl.innerHTML`.
  - `payopsClock()`: `$('#clock').html(...)` → `document.getElementById('clock').innerHTML`.
  - `$(document).ready(...)` → `document.addEventListener('DOMContentLoaded', ...)`.
  - `.each()` loop → `querySelectorAll(...).forEach(...)`.
  - `$('#q').length` / `.val()` / `.focus()` → `getElementById` + `.value` + `.focus()`.
- Added `keydown` listener on all `.exc-table tbody tr` elements: Enter or Space triggers `click()`.

### `public/mdl-3.css`
- Appended keyboard focus rule:
  `tr[tabindex="0"]:focus { outline: 2px solid var(--mdl-action); outline-offset: -2px; }`
  (WCAG 2.2 SC 2.4.7 Focus Visible).

## Controls applied
- Rule 01 (secure coding): no server-side logic changed; chip values are server-controlled
  enums (PENDING/REVIEW/HOLD/ESCALATED/RESOLVED, LOW/MED/HIGH) interpolated with `<%= %>` —
  not unescaped raw HTML from user input.
- Rule 02 (compliance headers): EJS headers added to all three views; JS header added to
  `payops.js`.
- Rule 03 (audit and change log): this entry.
- Rule 04 (approved libraries): jQuery 1.9.1 removed; no new library dependency added — all
  replacements are vanilla DOM APIs.
- Rule 09 (design system fidelity): chip markup, class names, and color tokens match
  `docs/design/KAN-41-spec.md` verbatim; styles sourced from committed `public/mdl-3.css`.
- NIST AC-3 / PCI Req. 7: access control — no route or data visibility change.
- NIST SI-10 / PCI Req. 6.5: input validation — template outputs escaped; no new unescaped
  interpolation introduced.
- NIST AU-2: audit — no change to server-side audit logging; compliance headers added.
- WCAG 2.2 AA findings resolved: (1) color-only risk encoding → labeled chips; (2) missing
  `scope` on `<th>` → added; (3) row keyboard selection → `tabindex="0"` + keydown handler +
  `aria-selected`; (4) sort column headers → `role="button"` + `aria-sort="none"`.

## Risk notes
- `utils.js` unchanged — `statusLabel` and `riskLabel` helpers remain available for the XML
  feed and any other consumer; the views simply no longer call them.
- `npm test` (40 Jest equivalence tests): all pass. The tests exercise server-side API behavior
  only and are unaffected by template or JS changes.
- Bootstrap 2 removal: the MDL 3.0 stylesheet already overrides Bootstrap 2 for all classes
  used in the Held Payments views. The Dashboard, Reports, and Help views are out of scope for
  this epic (see PLAN.md out-of-scope section) and still load Bootstrap via their own
  partials — but `header.ejs` is shared. Those views' Bootstrap-dependent classes are not
  styled by `mdl-3.css`, so their visual appearance may regress. This is a known accepted risk
  per the PLAN.md scope boundary; it can be addressed in a follow-on epic.
