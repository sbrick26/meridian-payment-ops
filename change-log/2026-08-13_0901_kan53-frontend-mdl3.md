## Controls applied

- Rule 01 (secure coding): All `<%= %>` output; `<%-` removed from exceptions.ejs status/risk/age. Credentials read from `process.env`.
- Rule 02 (compliance headers): Added to header.ejs, exceptions.ejs, payops.js, server.js.
- Rule 03 (audit trail): This entry.
- Rule 09 (design fidelity): Chip classes from `public/mdl-3.css`; values from `docs/design/KAN-51-spec.md` (frozen 2026-08-13).
- WCAG 2.2 AA: scope=col on th; aria-sort on sort headers; tabindex+aria-selected+keydown on rows; labelled chips for status and risk (not colour alone).
- Controls: AC-3, SI-10, AU-2 · PCI Req. 6.5, 7 · SOX ITGC

## Risk notes

- Removed `<%- u.statusLabel() %>` and `<%- u.ageCell() %>` — these returned HTML strings injected without escaping. Replaced with inline template chip markup using `<%= %>` only. No behaviour change for the user; XSS attack surface reduced.
- Bootstrap 2 and jQuery 1.9.1 unlinked. All DOM operations now use native browser API. `toggleBlock()`, `confirmAction()`, `payopsClock()` — behaviour preserved.
